# 🧪  Periodic Table

A cute, interactive periodic table with a glassmorphism design, a friendly mascot, a quiz game and a mini chemistry lab. Built with  **HTML, CSS and JavaScript**

**Live demo:** [https://periodic-table-2nza.vercel.app/]

---

## ✨ Features

### Explore
- All **118 elements** in the standard layout, with the lanthanides and actinides in their own rows
- **Glassmorphism design** with frosted tiles, soft gradients and smooth pop-in animations
- **Three colour modes**: by Category, by State (solid / liquid / gas) and by Block (s, p, d, f)
- **Search** by name or symbol, plus **filter chips** for each group
- **Hover highlight** (on computer) that lights up the same group and period
- **Light and dark mode** with a toggle that remembers your choice

### Element cards
- A cute mascot with a blinking face, drawn only with CSS
- Atomic number, mass, period, group, state, block and **electrons per shell**
- A speech bubble with a fun line for each category, and special lines for famous elements like Gold, Water-makers and more
- Previous / Next buttons, and keyboard arrows to move between elements

### Games and play
- 🎮 **Play mode**: find the element from its name or atomic number, with score, streak, best score, sound effects and sparkles
- ⭐ **Sticker collection**: every correct answer puts a star on that element (saved in your browser)
- 🧪 **Lab mode**: tap two elements to mix them, for example H + O = Water, Na + Cl = Table salt
- 🎲 **Random** button to meet a surprise element

### Made for everyone
- Fits the screen on laptops with no vertical scrolling
- Works on phones with no horizontal scrolling
- Keyboard accessible: use Tab to move and Enter or Space to open an element

---




## 🛠️ Built with

- **HTML5** for the structure
- **CSS3** with variables, grid, `backdrop-filter`, container query units and animations
- **JavaScript (ES6)** with no dependencies
- Web Audio API for the small game sounds
- `localStorage` to save your theme and sticker collection
